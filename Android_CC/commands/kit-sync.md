Keep `Android_CC/` current with what was actually used.

1. List the skills invoked or followed in this session (Skill tool calls, plus skills whose SKILL.md you read and applied).
2. For each one not yet in `Android_CC/skills/`, copy it from `~/.claude/skills/<name>/`. Even a single use qualifies.
3. For each one already present, refresh it if the installed copy is newer (`android skills update` first).
4. If the session produced a reusable lesson (a fixed build pattern, device pitfall, architecture
   pattern), add it to the matching agent/skill/rule, or create a new skill if none fits.
5. Update the inventory tables in `Android_CC/README.md` (name, source, first used in).
